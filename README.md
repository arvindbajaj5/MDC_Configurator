# AI Modular Data Center Configurator (V13.1 Enterprise)

Turnkey **Modular ISO Container** & **Brick-and-Mortar (BnM) Technical Hall** AI Data Center Engineering, Supply Chain Intelligence, 3D/CAD & Commercial Proposal Studio.

## Stack
- **Vite + React 18 + TypeScript + Tailwind CSS**
- **Three.js** interactive 360° 3D Container/BnM & Yard Twin
- **PptxGenJS** strict Pure-White (`#FFFFFF`) & Brand-Orange (`#FF5539`) native-shape presentation generator (`3.1"` blank footer clearance, zero slide logos)
- **jsPDF** native vector Engineering Dossier & Per-Unit Datasheet PDF generators
- **Vitest** automated engineering, supply-chain synthesis & backward-compatibility test suite
- **GitHub Actions CI/CD** (`deploy-pages.yml` + `monthly-supply-refresh.yml`)

## Quick Start
```bash
npm install
npm test
npm run dev
```
